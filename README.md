# ⚛️ React Development Journey — Day 1 & Day 2

A collection of small React projects built while learning React from the ground up.

Each project focuses on a specific set of React fundamentals. The goal is not to build production-ready applications yet, but to understand how React works by actually building and shipping small projects.

---

|-----|---------|------------|

**Main concepts learned:**
- React + Vite setup
- JSX
- Functional Components
- Component architecture
- Import & Export
- Rendering components

## ✨ Overview

Money Calculator is a lightweight money-tracking interface built with React and Vite.

The project displays:

- Income
- Total spending
- Remaining balance
- Expense breakdown

The data is currently static because the main goal of Day 1 was to understand the fundamentals of React rather than build a fully interactive application.

This project is the starting point of my React development journey.

---

## 🎯 Features

- 💰 Income overview
- 📊 Total spending
- 💵 Remaining balance
- 🧾 Expense breakdown
- ⚛️ Component-based architecture
- 🎨 Clean UI
